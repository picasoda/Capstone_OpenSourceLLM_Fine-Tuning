================================================================
  서버 실행 순서
================================================================

================================================================
  STEP 1. 가상환경 활성화
================================================================

  # PowerShell, 프로젝트 루트에서
  llm_env\Scripts\Activate.ps1

  # (또는 cmd일 경우)
  llm_env\Scripts\activate.bat

================================================================
  STEP 2. Ollama 서버 실행 (터미널 1)
================================================================

  # 현재 모델: qwen3.5:4b
  ollama serve

  # 모델 없으면 pull
  ollama pull qwen3.5:4b

  # 서버 재시작이 필요할 때
  taskkill /f /im ollama.exe
  ollama serve

  확인: http://localhost:11434  →  {"version":"..."} 응답
  모델 목록 확인: ollama list

================================================================
  STEP 3. FastAPI 챗봇 서버 실행 (터미널 2)
================================================================

  cd Chatbot
  python src/server.py

  확인: http://localhost:8000/health  →  {"status":"ok"}

================================================================
  STEP 4. ngrok으로 외부 노출 (터미널 3)
================================================================

  ngrok http --domain=bullring-reactive-ensure.ngrok-free.dev 8000

  → 고정 주소: https://bullring-reactive-ensure.ngrok-free.dev
  → ngrok 대시보드 (요청/응답 실시간 확인): http://localhost:4040
